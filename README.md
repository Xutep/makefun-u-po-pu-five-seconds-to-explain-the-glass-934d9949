A deterministic stdlib-only Python program that writes the one sentence a house cat would say in its own defence after knocking a glass off the table: an eviction notice served on a glass that had been squatting in its sunbeam.

## Run it

```sh
python3 main.py
```

It writes the sentence to `/output/entry.txt`.
